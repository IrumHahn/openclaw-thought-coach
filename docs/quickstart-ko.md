# 10분 퀵스타트 — 생각 코치

> 실행학교 2주차 화요일용. 명령은 **VPS 터미널**(OpenClaw가 설치된 곳)에서 실행합니다. 내 PC의 PowerShell이 아닙니다.

## 0. 준비물 (1분)

- 베이스캠프 > **에이전트 연동**에서 받은 토큰(`rap_s4_…`). 광장 스킬을 이미 쓰고 있다면 같은 토큰이라 준비 끝.
- 비서와 연결된 텔레그램 채널. (1주차에 연결했다면 그대로)

## 1. 설치 (VPS 터미널, 2분)

```bash
cd ~
git clone https://github.com/IrumHahn/openclaw-thought-coach.git
openclaw skills install ./openclaw-thought-coach/skill/thought-coach --as thought-coach --agent main
openclaw skills list | grep thought-coach
```

`ready │ thought-coach` 가 보이면 설치된 것입니다. 토큰은 OpenClaw 환경변수 `RUN_ACADEMY_PLAZA_TOKEN` 에 넣습니다(광장 스킬 설치 때 넣었다면 생략).

## 2. 시작 (텔레그램, 3분)

비서에게 이렇게 보냅니다:

```
생각 코치 시작해줘. 매일 밤 9시 반에 질문 하나, 아침 7시 반에 한 번만 리마인드.
첫 질문은 지금 바로 보내줘.
```

비서가 예약 시각 두 개와 채널 이름을 보여 주고, 첫 질문을 보냅니다. 질문에는 내가 쓴 회고 구절이 따옴표로 들어 있습니다.

## 3. 답하기 (매일 1~2분)

질문에 **한두 줄**로 답하면 끝입니다. 잘 쓰려고 하지 마세요 — 사실만 적어도 됩니다. 비서가 "오늘 1개째 생각을 저장했어요" 라고 돌려주면 저장된 것입니다.

- 4일 연속 답하면 한 생각이 **사실→이유→의미→주장**을 다 거쳐 "콘텐츠로 쓸 준비가 됐어요"가 옵니다.
- 답을 못 한 날은 아침에 한 번만 리마인드가 오고, 그래도 못 하면 저녁에 조용히 다음 질문으로 넘어갑니다. 미안해하지 않아도 됩니다.

## 4. 확인 (1분)

```
내 생각 현황 보여줘
```

질문·답 개수와 진행 중 스레드가 나옵니다. 파일로 직접 보려면 비서 워크스페이스의 `thoughts/` 폴더를 엽니다 — 날짜별 `.md` 파일이 내 글감입니다.

**3주차 화요일까지 목표: 답 7개 이상, 준비 완료 스레드 1개 이상.** 매일 답하면 자연히 됩니다.

## 막혔을 때

| 증상 | 해결 |
|---|---|
| "스킬이 안 보여요" | `openclaw skills list \| grep thought` → 없으면 설치 명령에 `--agent main` 을 붙여 다시 → 새 세션 열기 |
| "토큰을 다시 발급해 달라"고 해요 | 베이스캠프 > 에이전트 연동에서 재발급 → `RUN_ACADEMY_PLAZA_TOKEN` 교체. 광장 스킬도 같은 토큰을 씁니다 |
| 질문이 안 와요 | 비서에게 "오늘 질문 보내줘". 그래도 없으면 "생각 코치 예약 확인해줘"로 cron 등록 여부를 봅니다 |
| 회고를 아직 안 썼어요 | 괜찮습니다. 비서가 직접 "이번 주 기억에 남는 장면"을 묻습니다 |
| 에이전트 없이 돌려보고 싶어요 | SKILL.md의 "수동으로 하기" — 스크립트 세 개를 PC에서 직접 실행합니다 |
